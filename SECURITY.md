# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report vulnerabilities privately using one of these channels:

1. **GitHub private vulnerability reporting** (preferred when enabled on the
   repository): Repository → **Security** → **Report a vulnerability**.
2. **Email:** [patricphinehas@gmail.com](mailto:patricphinehas@gmail.com)

Include enough detail for us to reproduce the issue (affected version, steps,
impact). We will acknowledge your report as soon as we can and work on a fix.

## Supported versions

Security fixes are applied on the latest `main` branch and released as tags or
releases when available. Self-hosted deployments should track `main` or the
latest release.

## Disclosure

We ask that you give us a reasonable time to investigate and patch before
public disclosure. We will credit reporters who want to be named when we
publish a fix.
